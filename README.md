# A股30强 · 看好度监测

每月用多因子模型从沪深主板、创业板、科创板中选出 **30 只最看好的股票**。月内每个交易日（在 Mac 本地运行时**盘中每 1 分钟**）重新给这 30 只打分、重新排名。

每只股票有两个分数：
- **价值投资分**：中期，约 1 个月
- **短线分**：短期，约 1 周

页面上还会列出「近期要观察的事」：美联储议息、美股相关公司与大宗商品异动、中美关系、国内数据和政策等，并标出会影响哪些入选股。

> ⚠️ 本项目仅用于学习与研究，**不构成任何投资建议**。历史回测不代表未来收益，股市有风险。

## 一、怎么看网站

网站有两种用法：

| 用法 | 地址 | 更新频率 | 需要做什么 |
|---|---|---|---|
| 在线版（GitHub Pages） | `https://luffyxing55.github.io/A-Share-Analysis/` | 每个交易日收盘后（约北京时间 19:30–21:30）+ 开盘前（约 8:50） | 什么都不用做，手机也能看 |
| 本地实时版（Mac） | `http://127.0.0.1:8000` | 盘中每 1 分钟 | 运行一条命令（见下文） |

页面布局（一屏内完成「看榜单 + 看个股」，不用上下来回滑）：

1. **顶部行情条**：A 股主要指数、涨停/跌停/炸板家数；隔夜美股、半导体、中概、黄金、铜、原油、中美国债收益率；以及一个「市场状态」提示。
2. **左边：榜单**，可在「本月30强」和「科技周榜」之间切换，按综合 / 价值 / 短线排序：
   - 综合分 = 0.6 × 价值分 + 0.4 × 短线分。0–100 分，表示在全市场约 4000 只股票中的分位，越高越看好。
   - 「变化」列显示和上一交易日相比排名的升降；键盘 ↑ ↓ 可以逐只切换。
   - **科技股周榜（每周 15 只）** 独立于 30 强：只在电子、计算机、通信、传媒四个行业里选，每周最后一个交易日收盘后换一次名单。它在回测中的优势不如 30 强稳定，详见报告第 10 节。
3. **右边：所选股票的详情**（手机上点股票后全屏打开）：
   - **K 线图**（最近 1 / 3 / 6 个月）：上面是前复权股价 K 线（红涨绿跌）和 5 日 / 20 日均线，中间是成交量，下面是**看好分 K 线**（蓝色 = 比前一天升高，橙色 = 降低；本地实时模式下今天这根带盘中最高 / 最低）。可勾选同时显示价值分、短线分两条线。鼠标移上去（手机上按住）可以看每天的开高低收、成交量和当天的分数。
   - 网站上线前的历史看好分是**回算**的：每一天只用当天已经知道的因子权重，但短线模型用的是现在的模型，而且不含海外 / 新闻调整，所以只作参考。
   - 下面三个标签页：模型给分的主要原因、海外产业链联动（含历史统计出来的联动强度）、相关新闻。
4. **下方标签页「近期要观察的事」**：
   - 实时信号：海外异动（涨跌达到日常单日波动的 2 倍以上或超过 4% 才列出；达到 3 倍或 6% 才叫「大涨 / 大跌」；单日涨跌超过 40% 之类明显不合理的数据会被当作数据错误忽略）、美债收益率急变、融资余额变化、情绪极端等；
   - 未来 3 周的事件日历；
   - 当前的宏观主题。
5. **下方标签页「快讯与情绪」**：来自财联社、东方财富、新浪 7×24 的快讯，每条都有情绪打分。
6. **下方标签页「回测与方法」「科技周榜回测」**：回测净值曲线、分区间的业绩，以及上线后每个月 / 每周名单的真实表现。

## 二、在 Mac 上运行本地实时版

**第一次使用：**

1. 安装 Homebrew（如果还没有）：打开「终端」，粘贴 https://brew.sh 首页上的那条命令。
2. 安装 Python 和 git：

```bash
brew install python@3.12 git libomp
```

3. 下载项目：

```bash
git clone https://github.com/LuffyXing55/A-Share-Analysis.git
```

4. 进入项目文件夹，一键启动：

```bash
cd A-Share-Analysis && bash scripts/start_mac.sh
```

脚本会依次完成下面这些事：

- 创建虚拟环境并安装依赖。国内网络如果 pip 很慢，可以先运行 `export PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple`。
- `git pull` 拉取 GitHub 每天自动算好的最新结果。
- 如果本地还没有数据，自动做一次完整计算。首次需要下载约 570MB 历史数据。
- 启动本地网站，并自动打开浏览器。

**以后每天使用**，只要运行这一条：

```bash
cd A-Share-Analysis && bash scripts/start_mac.sh
```

交易时间内页面右上角会显示「● 盘中实时（本地）」，每分钟自动刷新。盘中实时版具体做了这些事：

- 每 1 分钟用腾讯行情拉取 30 只股票的最新价，把「今天到目前为止的 K 线」（成交量按已交易时长折算成全天）拼进历史数据，用**同一个模型**重新计算价值分和短线分；
- 每 10 分钟刷新一次海外行情，每 3 分钟刷新一次新闻；
- 排名「变化」列表示相对于昨天收盘后的排名。

**想在本地重算全部数据**（比如 GitHub 没有更新时）：收盘后运行 `bash scripts/update_mac.sh`。

## 三、GitHub 自动运行（已配置好）

`.github/workflows/daily.yml` 在每个交易日自动运行：

| 北京时间 | 做什么 |
|---|---|
| 约 19:23（兜底 21:07） | 完整计算：下载最新日线 → 计算全市场因子与两个分数 → 月末选出下月 30 强 → 每日排名 → 抓取海外/新闻/事件 → 把结果提交到 `site_data/` 并发布网页 |
| 约 08:47 | 开盘前：刷新隔夜美股联动信号、新闻和观察清单 |

需要在仓库设置里打开两项（只需一次）：

- **Settings → Actions → General → Workflow permissions** 选 **Read and write permissions**；
- **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。

也可以在 **Actions → 每日更新与发布 → Run workflow** 手动运行一次。

注意：

- GitHub 的定时任务可能晚 15–120 分钟才开始，这是正常现象。
- 公开仓库连续 60 天没有提交时，GitHub 会自动停用定时任务。本项目每天都会提交数据，一般不会触发；万一被停用，到 Actions 页面点 **Enable workflow** 即可。

## 四、选股方法（简要）

完整说明和全部数据见 [`docs/方法与回测报告.md`](docs/方法与回测报告.md)。

- **股票池**：剔除以下股票——ST、退市整理、上市不满约 1 年、停牌多、日均成交额低于 2000 万元或处于全市场最低 15%、股价低于 2 元。
- **因子**（25+ 个）：
  - 估值：E/P、B/P、ROE
  - 风险：波动率、特质波动、近期暴涨
  - 交易拥挤度：换手率、异常换手、非流动性
  - 反转：1/5/20 日、长期
  - 量价背离、隔夜/日内结构、近期涨停次数、市值
  - 行业动量与行业内相对强弱
- **价值投资分（中期）**：「尾部加权合成」。A 股多数因子的收益主要来自「避开最差的股票」，而只买 30 只需要的是「最好的那一端」。所以逐个因子统计它「前 5% 股票」随后 20 个交易日的超额收益，每月只用过去 36 个月已实现的数据，选出 t 值 ≥ 0.5 的因子按 t 值加权（不保证每个时段都为正）。**不使用「小市值」因子**，不会因为市值小直接加分；并且价值分在 5 个市值组内各自比较（大盘股和大盘股比、小盘股和小盘股比），避免「非流动性」等因子间接偏向小盘股。另有估值约束：只选盈利、且 PE 低于盈利公司 70 分位的公司（排除盈利公司里最贵的 30%）。
- **短线分**：LightGBM 模型预测未来 5 个交易日的相对收益（同样不使用市值），每次训练只用过去的数据。
- **回测结果**（扣交易成本，详见报告第 6 节）：
  - 2016 年至今：年化 12.3%，基准（股票池等权）1.3%，**年化超额 +11.0%**，信息比 1.19；2025 年以来年化超额 +11.8%。
  - 这些数字是**乐观的上限**：部分参数和「去掉小市值加分」等决定是在看过全部历史数据后做出的，并不是严格的样本外检验。真实效果请看网站上线后每个月的「实盘跟踪」。
  - **现行规则**（加上价值分市值中性化，2020 年起算，因为市值数据从 2020 年才有）：换用 6 个短线模型版本分别回测，年化超额中位数 **+9.6%**（各版本 +7.6% ~ +12.3%），信息比中位数 0.93；2025 年以来中位数 +6.2%。Top30 对模型的细微差别很敏感，单个版本的回测数字不可靠，请看范围。详见报告第 6.6、6.7 节。
  - 上面「2016 年至今」的数字也只是一个模型版本的结果，同样可能偏高或偏低。
  - 测试过「每周重选 30 只」：长期略差于每月（中位数 +7.5% 对 +9.6%）、换手约翻倍，所以保持每月重选。
  - 最大回撤：2016 年起 −47%、2020 年起 −28%。不择时，大盘下跌时会一起下跌；入选股仍偏中小盘（短线分偏小盘）。
- **海外联动**：37 条「美股/大宗 → A 股产业链」映射（例如英伟达 → 光模块、黄金 → 黄金股）。用 2016–2022 年数据估计每对的联动系数，在 2023–2026 年做样本外检验：样本内显著（t 值绝对值 ≥ 2）的配对，对次日开盘跳空的预测相关性约 0.22，对全天超额收益约 0.13；黄金、白银、铜、原油链最强。只有检验显著的配对会计入短线分。
- **新闻情绪**：自建的财经情绪词典 + 否定词规则，只作为小幅调整（最多 ±6 分），未经回测。
- **回测规则**：
  - 次日按成交均价成交；一字涨停买不进，一字跌停卖不出；
  - 交易成本：买入 0.15%，卖出 0.25%（含印花税）；
  - 数据包含已退市股票，避免只看「活下来的股票」造成的偏差。

## 五、项目结构

```
ashare/
  data/        历史数据读取（Qlib 二进制）、行业分类
  factors/     因子库（回测与实盘共用同一份代码）
  model/       模型训练、打分、可解释性
  backtest/    回测引擎（涨跌停、停牌、成本）
  live/        数据源（腾讯/新浪/东财/财联社/海外）、盘中实时重算
  macro/       海外产业链映射、事件与观察清单
  news/        新闻情绪
  pipeline/    每日流水线
  research/    研究与实验脚本（IC 分析、模型对比、联动检验）
  server/      本地实时网站
config/        参数、事件日历（可编辑 events.json 增删事件）、联动统计
models/        训练好的模型
site_data/     每日结果（由 GitHub Actions 自动更新）
web/           网页
docs/          资料汇编、方法与回测报告
```

## 六、常见问题

- **页面显示「数据加载失败」**：在线版说明 Actions 还没成功运行过，去 Actions 页面看一下；本地版请确认 `site_data/dashboard.json` 存在。
- **本地实时版分数不动**：非交易时间每 15 分钟才刷新一次。也可以在终端里查看报错，或访问 `http://127.0.0.1:8000/api/status`。
- **想改参数**：编辑 `config/settings.json`，比如 `top_n` 是入选股票数，`industry_cap` 是同一行业最多几只，`score_weights` 是综合分里价值分和短线分的权重。
- **想加事件**：编辑 `config/events.json`，按已有格式添加即可。

- 实时行情：腾讯、新浪
- 财务/两融/国债/龙虎榜：东方财富数据中心
- 快讯：财联社、东方财富、新浪
- 海外：腾讯美股、新浪外盘期货

原始数据的版权归原提供方所有。本仓库**不保存全市场原始数据**（日线、财务、行情缓存都在 `.gitignore` 里，只留在运行环境中）。仓库和网站里只有：

- 计算结果：分数、排名、因子统计、回测净值；
- 入选的几十只股票最近 6 个月的 K 线，用于画图；
- 快讯只发布**标题、来源、时间、原文链接**和情绪分，不转载正文。

如果某个数据提供方认为本项目的使用方式不合适，请提 Issue，我们会尽快删除相关内容。

## 八、合规说明
