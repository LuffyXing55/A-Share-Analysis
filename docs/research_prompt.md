# 任务：为「A股月度30强选股 + 实时看好度监测」量化网站做全面资料调研，输出一份完整的资源文档

## 背景
我是负责写代码的 AI 工程师，要做一个 A 股分析网站，功能如下：
- 每月初从沪深主板、创业板、科创板中选股（先剔除 ST/*ST、上市不满 1 年、长期停牌、流动性差的股票），用多因子模型选出 30 只最看好的股票。
- 月内每天（盘中每几分钟）根据所有数据实时更新这 30 只股票的「看好分数」。分数分两种：「价值投资分」（中长期）和「短线分」（1–10 个交易日）。每天给出排名调整。
- 生成「近期要观察的事」：比如美联储议息、美股相关个股或指数的涨跌、汇率、大宗商品、国内政策，分别会对每只股票或行业产生什么影响。
- 用尽可能多的近期历史数据回测，并反复迭代优化算法。

运行方式有两种。第一种是用户的 Mac（在中国大陆网络下）本地运行 Python 服务，实时抓数据。第二种是 GitHub Actions（美国机房 IP）每天定时计算，再发布到 GitHub Pages。

我的开发环境只能访问 GitHub（github.com、raw.githubusercontent.com、Release 下载）和 PyPI/npm，访问不了任何国内网站，也访问不了 Yahoo 等网站。所以我非常依赖你给出准确、经过验证的信息。

今天是 2026 年 11 月 3 日。如果你查到的最新日期不同，以你查到的实际最新日期为准。
